# 📁 Setting Up an Odoo Document Management System for a Company

## 🏢 Scenario

You are part of the IT department at **Digitera Ltd.**, a company providing software development, consulting, and support services.

The management has asked you to set up a **document management system** using **Odoo Documents** on [Odoo.com](https://www.odoo.com), so departments have one place for their files.

---

## 🎯 Objectives

In this exercise, you will:

- Install the **Documents** app
- Create the company folder structure
- Upload one document into that structure

---

## 🧰 Prerequisites

- A free Odoo Online database ([Odoo.com](https://www.odoo.com), **One App Free**)
- The **Documents** app

### Create the database and install Documents

1. Open [Odoo Documents](https://www.odoo.com/app/documents)
2. Click **Start now**
3. Use your school email and set the company name to `Digitera Ltd.`
4. When asked which app to install, select **Documents**

If Documents is not in the menu yet:

1. Open **Apps**
2. Search for `Documents`
3. Click **Install**

---

## 1️⃣ Step 1: Explore Documents

1. Open the **Documents** app
2. Look at the tree on the left:
   - **Company** — files for the whole company
   - **My Drive** — your own files
   - **Shared with me**
   - **Recent**
   - **Trash**
3. Open **Company**

---

## 2️⃣ Step 2: Create the folders

1. Select **Company**
2. Click **New → Folder**
3. Name it `Company Documents` and save
4. Open `Company Documents` and create these folders inside it:

   - `Internal Docs`
   - `Private`
   - `Marketing`

---

## 3️⃣ Step 3: Upload one document

1. On your computer, create a short Word, text, or PDF file with this sentence:

   `Digitera document archive and internal documentation`

2. In Odoo, select `Company Documents`
3. Click **New → Upload** and upload the file

---

## ✅ Expected outcome

By the end of the exercise, you should have:

- An Odoo database with the **Documents** app installed
- The folder `Company Documents`, with `Internal Docs`, `Private`, and `Marketing` inside it
- One uploaded file in `Company Documents`
